VideoJuego • Gdevelop • Lógica de programación

Completado
Descripción del proyecto

Videojuego realizado con la plataforma de GDevelop, implementando lógica de programación básica y eventos de colisión, clics entre otros eventos. El juego cuenta con tres niveles en los cuales el primer nivel consiste en llegar al portal para continuar con el siguiente nivel, el segundo se desbloquea pasando el primero y en este nivel hay que eliminar un total de 25 robots para desbloquear el portal al siguiente nivel. Sistema Historial Ventas Pantalones

Programa de Historial ventas • Windows Forms • C#

Completado
Descripción del proyecto

Aplicación de escritorio para registrar y gestionar ventas de pantalones (talla, tela, color, género, precio y cantidad), construida en C# (.NET Framework 4.7.2) con Windows Forms. Este proyecto fue desarrollado como proyecto final académico y permite registrar nuevas ventas, visualizar el historial completo, editar o eliminar registros, y obtener estadísticas básicas como la ganancia total, la tela más vendida y el color más vendido. Este proyecto se hizo pensando en negocios locales para mejorar el proceso de venta en el día a día y dando estádisticas de lo vendido para comprar mercancía según las tendencias.

Lo aplicado

Lógica de programación al realizar una acción en un botón, registro de ventas de pantalones por medio de labels (formulario) y visualización del historial, los datos almacenados no son percistentes.

Acciones

Se desarrollo el programa en Visual Studio 2022, en el lenguaje de programación de C# con la herramienta de Windows Forms y luego se subió el proyecto a GitHub con su respectivo ejecutable.

SafeMoney

Programa Desktop • Java • POO

Completado
Descripción del proyecto

Proyecto que se enfoca en poder administrar bolsillos de usuarios para que administren y separen sus ingresos por categorías, permitiendo gestionar el dinero destinados a Servicios, gastos fijos, gastos hormiga, y ahorros fijos. Este proyecto nace de la necesidad de que las personas no saben suministrar muy bien sus ingresos, por ejemplo llega fin de mes y la plata no les alcanza para cosas básicas, haciendo que recurran a prestamos o deudas. Desarrollo de un sistema que permita iniciar sesión, registrarse y administrar diferentes bolsillos en los cuales se podrá destinar el dinero a bolsillos en especifico clasificando todos los ingresos.

Lo aplicado

La mayoria de conceptos de Programación Orientada a Objetos, la utilización de libreria Java Swing, lógica de programación para iniciar sesión, validaciones sencillas de campos.

Acciones

Desarrollo en herramienta intuitiva de Java Swing, lógica del negocio con el lenguaje de programación Java en el entorno de desarrollo IDE Apache NetBeans, subir proyecto a GitHub.

JJConsulting

Página web • Frontend y Backend• HTML • CSS • JavaScript

Completado
Descripción del proyecto

Practica profesional en técnico profesional de desarrollo de aplicaciones de software en la empresa de Asesorías Contables y Administrativas JJ S.A.S. Desarrollo de página web totalmente personalizable a medida, con formulario funcional con almacenamiento de base de datos, estructura de página web y estilización. Contiene una estructura de Frontend y backend por aparte y base de datos gratuita en Neon.tech. El Frontend está alojado en Vercel y el Backend enRailway.

Lo aplicado

Se aplicó conocimientos en backend con SpringBoot utilizando el Modelo Vista Controlador para el manejo de datos que se ingresan en el Frontend. Por otro lado la estructuración y estilización basica con HTML y CSS, junto con la lógica de JavaScript para validar datos. Por otro lado el uso de diferentes herramientas como por ejemplo Inkscape (para la vectorización de figuras), Vercel (alojamiento web estatico), Render (alojamiento web backend) y Neon.tech (Alojamiento web de base de datos).

Acciones

Se desarrollo el Backend en Java con la dependencia de SpringBoot para conectar y almacenar los datos más facil y rapida en IntelliJ IDEA. Por otro lado se continuó con el Frontend desarrollandolo en Visual Studio Code con HTML, CSS y JavaScript. Por último, se alojo cada herramienta o sección del código como servicio en la nube para utilizar y unificar la página web. Luego para el Frontend y el backend los subí al repositorio de GitHub en privado para que cada proveedor de alojamiento leyera el contenido sin tener que ponerlo publico.
